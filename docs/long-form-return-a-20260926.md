## 現仕様

- 20/30/60/90秒は変更しない。
- 120秒の休止・復帰・B開始・終端接続開始は90秒版と同じ。
- 同じテンポの90秒ループの実尺まで進めた後、通常のAへ戻って曲末まで続ける。
- 接続最後の小節も、追加Aに向かう従来のA型を使う。ループ接続用の打楽器・旋律終端処理などは完全な波形一致の対象外。
- 休止の最大4小節・16秒以内は維持。
- 場面専用経路が対象。疑惑のautoPattern・手動伴奏にはB切替を新規追加していない。

60 BPMの実際の時刻（秒）：休止44〜60、A60〜68、接続68〜72、B72〜76、接続76〜92、A92〜120。以前の会話の「休止48〜64」は計算誤りだった。約45秒に最も近い小節頭は44秒。90秒版を維持する要件を優先し、コードは動かさない。
76 BPMでは90秒の実尺が約91.58秒なので、そこから最後のAへ戻る。秒数のために小節を切らない。
