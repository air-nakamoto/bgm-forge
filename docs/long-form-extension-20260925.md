# 長尺の延長構成（2026-09-25）

この文書は旧案の記録。120秒のB延長は [2026-09-26のA追加構成](long-form-return-a-20260926.md) に置き換え済み。

ユーザー方針：指定秒数は目安。小節・場面のまとまり、休止と復帰の自然さ、短い曲を延ばしたときの流れを優先する。120秒は90秒の構成を延長する。

## 実装

- 20/30秒：従来どおり。
- 60秒：末尾に内声休止。長さは最大4小節・16秒以内。
- 90/120秒：A → 約45秒に近い小節頭から休止 → Aを2小節 → 接続1小節 → B → 終端接続 → ループ。
- 120秒だけ約30秒で休止する処理、休止後Aを4小節にする処理、約90秒でAへ戻す処理を撤去。
- 終端接続は原則末尾4小節。B区間が短くなる場合も少なくとも1小節残す。
- 休止は `min(4, floor(16秒 / 1小節の秒数))` 小節（最低1小節）。対応テンポ46 BPMで3小節=約15.65秒、それ以外の対応テンポでは従来の4小節。16秒は既に試聴済みの60 BPMの休止を保つ初期基準であり、聴感の万能閾値ではない。
- 実尺の既存の小節丸めは維持。全曲無音にはしない。

## 適用範囲

休止は場面専用・autoPattern・手動伴奏の共通処理。B切替は従来どおり場面専用経路で、疑惑のautoPatternや手動伴奏へ新規追加はしていない。
新規作曲と編集による90→120秒延長で、終端接続前の伴奏を一致させる。旋律の終端持続・全曲正規化・残響による違いがあるため、音声波形や全旋律の完全一致は要求しない。
