# 全場面の音声品質監査（2026-09-23）

ユーザーの確認：幻想のループ修正Bは「いいかんじ」で採用。儀式・のどかの既定ループは違和感なし。
今回はそれ以外の音の破綻を調べた。**短い主題で旋律が空になり内声の音域を壊す不具合を1件確認し、修正した。**
音の良さ・音楽的な自然さを数値だけで合格判定したものではない。

## 確認した範囲

- 楽譜：24場面 × 5seed（1/42/101/2026/9999）× 6テンポ × 6指定尺 × ループ/終止 × 旋律オン/オフ＝17,280設定。
  各場面の既定音色・既定phrasing。音符の数値、MIDI音高と強さ、開始・持続・終端、同パート同音の重複、旋律の有無を検査。
- 実音声：Chrome OfflineAudioContext、44.1kHz・ステレオ、178条件。
  全24場面の30秒指定×2seed×旋律オン/オフ＝96、120秒指定の既定設定＝24、終止ありの既定設定＝24、
  幻想と緊迫で旋律オンにして全17音色へ切り替え＝34。長尺はseed 42、終止と音色切替はseed 2026。
- 不具合の追試：46 BPM・20秒指定で全24場面×100seed×ループ/終止×4種類の旋律量＝19,200設定。
  修正前後の音声は和風・儀式×2seed（101/9999）＝4条件ずつ。MIDI出力も和風seed 101で検証。
- 元のテストに短い主題の回帰検証1,632ケースを追加。既存の7,200作曲検証・816場面ケース等もPASS。

## 見つかった不具合と修正

20秒・46 BPMは主題が2小節になる。「ごく少ない」では最初の小節を休み、2小節目も抽選で休むことがある。
すると `melody=[]`、最低音の初期値 `melodyLow=999` が残り、旋律オン時にその下へ内声を配置してMIDI音高995を生成した。
既定の旋律量で再現したのは和風・儀式。編集で他場面を「ごく少ない」にした場合にも起こる。

- 合成音では可聴域を大幅に超える分音を生成しないため、その内声が鳴らなくなる。
- 箏は音域の折り返し処理があるが、楽譜データ自体は範囲外のまま。
- MIDI出力は音高をバイト列へ直接書くため、不正なデータになる。和風seed 101では規格外のデータバイトが16個あった。

**修正：主題が最後まで全休符になる場合に限って、最終小節に1音を残す。最低音の未定値999も廃止した。**
既存の旋律がある曲の選音やリズムは変更しない。

| 指標 | 修正前 | 修正後 |
|---|---:|---:|
| 全設定17,280ケースの異常ケース | 5 | 0 |
| 短尺追試19,200ケースの空の旋律 | 1,733 | 0 |
| 短尺追試の音域外データを含む曲 | 1,599 | 0 |
| 短尺追試の最大MIDI音高 | 995 | 86 |
| 和風seed 101のMIDI規格外データバイト | 16 | 0 |

短尺追試でもともと旋律があった17,467ケースは音符列が変更前と完全一致。
実音声監査178条件の全スコア・音符列も変更前後で完全一致を確認した。したがって、178条件の音声を無用に再レンダリングせず、
変更が出た4条件を修正前後で実音声化した。音声合成コードは変更していない。
修正前後の4条件ではエラー・非数値はなく、旋律は0→1音、最大音高は988〜995→69〜72になった。
これは欠損と範囲外データの解消であり、聴感の改善は別途確認する。

## 実音声178条件の結果

| 指標 | 結果 |
|---|---:|
| 生成エラー | 0 |
| NaN・無限大を含むサンプル | 0 |
| 振幅の絶対値が1を超える曲 | 0 |
| ピーク振幅の範囲 | 0.1595〜0.8727 |
| 全曲RMSの範囲 | 0.04478〜0.07468 |
| 振幅の絶対値0.94以上のサンプル | 0 |
| 20ms窓RMSが0.00001未満の窓 | 0 |
| DC成分の最大絶対値 | 0.000467 |

RMSが約0.045の曲は鎮魂で、既存の音量目標が他場面の約0.075より低い仕様。
「全曲RMSの1%未満（−40dB）」の弱い区間は儀式で最大1.08秒あった。絶対無音ではなく、
既定の儀式はユーザーの試聴で問題なしなので、この指標だけを理由に音を足したり増幅したりしていない。

波形の隣接サンプル差や左右の相関は、矩形波・高域の打楽器・左右に広げた持続音でも大きく動く。
チップチューンの継ぎ目の差0.0802も、同じ曲の内部の差の99.9百分位0.1298以下だった。
段差があるだけでクリックや破綻と判定しない。最も大きい曲中の変化については追試結果を末尾に記録する。

## 保存場所と再実行

- 汎用監査：`scripts/audit_audio.cjs`。楽譜だけなら `BGM_SCORE_ONLY=1 node scripts/audit_audio.cjs 'Claude outputs/score-audit'`。
- 音声も測る場合はPlaywrightを読める `NODE_PATH` とChrome実行ファイルの `BGM_CHROME` を指定し、
  `node scripts/audit_audio.cjs 'Claude outputs/audio-audit'` を実行。必要なのはローカルのブラウザと同梱音源で、外部APIは使わない。
- 生JSON・音声・修正前後のソースと比較スクリプト：`Claude outputs/全場面音声監査-20260923/`（Git対象外）。
- 修正例の音源：`短尺旋律修正/after-japanese-101.wav` と `after-ritual-101.wav`。
  20秒指定・46 BPM・「ごく少ない」・旋律オンの修正後。鳴らして確かめてください。
