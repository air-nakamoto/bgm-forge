2026-09-27整理。旧2026-09-23版は [履歴](../HANDOVER_HISTORY.md) に保存した。現仕様は [HANDOVER](../HANDOVER.md)、優先順・完了条件は [統合レビュー](review-20260927.md) を参照する。

## 実装済みの事項

- 1分以上のループ実尺は4小節単位で指定以上へ切り上げる。
- 場面専用・autoPattern・手動伴奏の長尺休止を通常テストで検証する。疑惑のwave経路も長尺Bに対応している。
- 長さ編集時にテーマを再選択し、必要なら旋律を再生成する。
- 休止後のA復帰は96 BPM未満8拍／以上16拍。120秒は90秒構成完了後にAを追加する。
- 夜空×オルゴールの音量補正、幻想×ガラス・鐘のパッド補正は採用・実装記録がある。ただし当時のWAVと現仕様の比較結果は別途確認する。
- 単体版一致とJS参照ハッシュは通常テストが検査する。専用CIはない。

## 残る課題

- 鎮魂コラール・疑惑・荘厳の長尺B、休止復帰、他seed・テンポの聴感確認。
- 持ち越し音と残響、音色別バランス。全曲RMSだけで持続音・減衰音の知覚音量を比較しない。
- 固定条件で9設定が8種類になる9場面の伴奏重複。数値と比較試聴の後に最小修正を判断する。
- ダイアログのフォーカス制御、テイクのJSON保存・復元。
- 既存の音高検算テストを維持し、サンプル追加・変更時も検算する。復号キャッシュ変更時の二重復号回避と、原音取得・再生成手順の整理が残る。
- Firefox・Android実機。旧外部テストは当リポジトリに存在せず、現行のテスト範囲は [テスト手順](../tests/README.md) に明示する。
- Git保守は別作業。①のレビュー完了まで実行しない。

五音音階の和音が広すぎるとは未確定。旋律候補と実際の同時発音を分けて計測する。別旋律・転調・新機能の一律追加より、合意した検証を優先する。
