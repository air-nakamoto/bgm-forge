## 優先度の高い課題

### 長尺構成の機械的反復

現行の長尺展開は内声の休止・別型・復帰まで実装済みだが、旋律や和音進行は主題を維持している。A′・B・別旋律・別コード進行による変奏は未実装で、場面によっては反復感が残る。

### 編集後の音量バランス

夜空×オルゴールはBの試聴採用と本体実装が完了（`2c805e6`）。他音色・場面は未採用で、一律の補正は行わない。
対象の長尺・プレビューと処理負荷、他音色の聴感評価が残る。全曲RMS正規化だけでは持続音と減衰音を同じように扱えない。
今回の経緯と状態の記録方法は [音の調整から公開まで](audio-change-workflow.md) を参照。

### `autoPattern` と長尺制御の分離

`autoPattern` を持つ場面（例: 疑惑）は場面専用の `SCENES` 経路を通らないため、長尺の内声休止・別型制御が統一されていない。

## データ整合性・品質リスク

- 実録音4種（シタール・箏・笛・合唱）は、ファイル名ではなく波形から音高を検証する運用を継続する。
- サンプルバンクは復号後にPCMを破棄するため、復号キャッシュの変更時に二重復号や `atob(undefined)` を起こさない。
- Freesound原音は大容量のためリポジトリに含めていない。再生成手順と取得条件の文書化が必要。

## アーキテクチャ上の課題

- 旋律の跳躍は半音基準に直したが、`chordDegrees` は度数基準で、五音音階では和音が広がりすぎる可能性がある。
- 持続音と減衰音の知覚音量を比較する自動指標がなく、音色追加時に手動調整が必要。
- 打楽器に場面専用経路とlegacy経路があり、変更箇所を誤ると効果が出ない。

## テスト・運用の穴

- `scene-variation.cjs` は譜面・生成整合性を検査するが、聴感、ループ継ぎ目、長尺の退屈さは人間の試聴が必要。
- 旧 `inside-rooms/tests/` の再生・ブラウザ・ループ・seamテストは未移行。
- Firefox・Android実機でのCSSと音声確認は未実施。
- 単体版生成と `?v=` 更新は手順依存で、専用CIはない。

1. 長尺の旋律・和声変奏を小さな実験として実装し、代表4場面（幻想・民族・思索・追跡）を試聴する。
2. `autoPattern` 場面に4小節休止と別型を適用する共通経路を設計する。
3. 編集後の音色別バランスを計測し、聴感で採用した補正だけを回帰テストに固定する。
4. 旧テストのうちループ継ぎ目とブラウザ再生に直結するものから移行する。
5. 音源再生成手順、場面数・音色数などのREADME記載を実体から自動検査する。

## 改訂した改善計画（2026-09-23）

新しい変奏を増やす前に、既存の長尺仕様とテストを立て直す。以下は計画であり実装完了ではない。

1. **実尺・休止・別型・復帰を検証する。** 全24場面・主要テンポ・複数seedの60/90/120秒を対象に、新規作成と30秒曲からの編集延長を比較する。予定の区間が曲中に存在することを先に確認する。
2. **セクション構成を共通化する。** 通常・休止・別型・復帰を共通データで管理し、場面専用・autoPattern・手動伴奏への適用漏れを防ぐ。内声のない場面の扱いも明示する。
3. **同一seedのA/B比較を作る。** 幻想・民族・思索・追跡・疑惑で音符列、パート別音量、休止長、ループ接続を測る。実音の余韻も確認し、最後はユーザーに鳴らして確かめてもらう。
4. **旋律の応答変奏と音色補正を個別に試す。** 元のテーマの後半だけを変える案から始める。補正は問題が測定できた音色・帯域だけに適用し、試聴で採用したものを固定する。
5. 旧再生・ループ・ブラウザテストの移行、原音取得手順、README定数の照合を進める。

### 先に解消する不一致

- 約4小節休止は未保証。現行は秒数を小節開始時に判定する。15秒は4小節と同義ではなく、4/4の4小節は60 BPMで16秒、120 BPMで8秒になる。
- 内声休止は全曲無音ではない。低音・和音・打楽器・旋律は残る。全曲無音を実装済みとは扱わない。
- 60秒・90秒指定は実尺不足で予定の休止・別型に届かない場合がある。
- 60秒のテストは `sixtyEvents.length >= 0` という必ず通る条件で、120秒の休止検査も欠ける。絶対時刻の違いだけで別型を証明せず、区間内の相対時刻で音符列を比較する。
- 全テストPASSは長尺要件の達成や聴感の合格を意味しない。

### 外部AI案の評価

| 案 | 判断 |
|---|---|
| 共通セクション構成・同一seedのA/B比較 | 優先する |
| 旋律の問答・後半変奏 | 次の実験候補。テーマ、音域、跳躍を保つ |
| 音色別EQ・パート別音量評価 | 条件付き。提案のLUFS値や周波数を根拠なく採用しない |
| 打楽器のフレーズ変化 | 小規模比較。会話を邪魔するフィルを増やしすぎない |
| 転調・複雑な経過和音 | 後回し。旋律との衝突、場面らしさ、ループ接続の検査が必要 |
| RMS最小点へのループ移動 | 現段階では見送り。振幅の小ささは拍・和声の自然な接続を保証しない |
| 指数減衰・デチューン・ターンアラウンド | 現行コードに存在する。未導入という前提で追加しない |

スペクトル重心やクレストファクターは診断の補助指標とし、数値が変化しただけで自然さや音質向上を断定しない。
