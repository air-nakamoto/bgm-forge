# BGM Forge 人間による品質チェックリスト

最終更新: 2026-09-25

入口: [評価ツール一覧](quality-evaluation.md)。未試聴はINCOMPLETE、仕様上対象外はN/Aとして記録する。
A/Bは可能なら名前を伏せ、順序を入れ替えて比較する。違和感は秒位置も記録する。

自動テストでは判断できない「自然に聴こえるか」「場面に合うか」を、人間が確認するためのリストです。数値だけで合格にしません。

## 試聴条件

- [ ] 同じ音量・同じ再生環境で比較する
- [ ] 可能ならヘッドホンとスピーカーの両方で確認する
- [ ] 1曲だけで判断せず、同じ場面を3seed以上聴く
- [ ] 変更前後を同じseedで比較する
- [ ] 先に指摘内容を読まず、第一印象を記録する

## 1. ループ

- [ ] 先頭から末尾まで聴いた
- [ ] 末尾から先頭へ戻る瞬間にクリックがない
- [ ] 音量が急に落ちたり跳ねたりしない
- [ ] 和音が不自然に重ならない
- [ ] 残響やリリースが途中で切れない
- [ ] 2回以上ループしても違和感が増えない

## 2. 長尺展開

- [ ] 60秒の反復が用途上退屈すぎない（意図的な反復そのものは不合格にしない）
- [ ] 休止区間が「故障」ではなく意図的な余白に聞こえる
- [ ] 別型への切り替えが急すぎない
- [ ] 120秒で終盤の復帰が自然
- [ ] 会話や作業の邪魔になる急なフィル・高音・音量変化がない

## 3. 場面らしさ

- [ ] 場面名から期待する雰囲気がある
- [ ] 3つのseedを聴いても同じ場面に聞こえる
- [ ] 3曲が同じ曲の色違いだけになっていない
- [ ] 伴奏と旋律が互いに邪魔をしていない
- [ ] 旋律なしでもBGMとして成立する

## 4. 音色・音量

- [ ] 旋律だけが過度に前に出ていない
- [ ] 旋律が伴奏に埋もれていない
- [ ] 持続音が耳に張り付かない
- [ ] 撥弦・鐘・オルゴール音が細く硬くなりすぎていない
- [ ] 合唱・笛・箏などの実録音が自然に聞こえる
- [ ] 高音の「ぴーん」、低音の濁り、耳障りな反復がない

## 5. 操作・保存

- [ ] 場面変更、再生成、試聴が迷わず行える
- [ ] 音色・テンポ・旋律量の変更が試聴に反映される
- [ ] 長尺生成中に画面が固まったように見えない
- [ ] 保存したWAV/MP3を外部プレイヤーで再生できる
- [ ] 単体版をオフラインで開いて主要機能が動く

## 判定

- PASS: 明確な違和感なし
- CONDITIONAL: 軽微な違和感があるが用途上許容。理由を記録
- FAIL: クリック、破綻、場面不一致、過度な単調さ、操作不能のいずれか
