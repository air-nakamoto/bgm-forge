# BGM Forge 品質チェックリスト

最終更新: 2026-09-25

入口: [評価ツール一覧](quality-evaluation.md)。依存を追加する際は [ライセンス台帳](evaluation-tool-licenses.md) を更新する。
各項目は実施結果の記録がある場合だけチェックする。対象外はN/Aと理由、未取得はINCOMPLETEとする。

この文書は、BGM Forge の変更を検証するときの機械的なチェック項目です。音の良し悪しは判定せず、壊れていないこと・仕様どおりであること・再現できることを確認します。

## 判定ルール

- すべての必須項目が PASS になるまで「検証完了」としない。
- FAIL が出たら、音の調整や新機能追加を止め、原因を特定する。
- 数値が改善しても、人間の試聴を通過するまで品質改善とは断定しない。
- 検証には commit、seed、設定、実尺、生成日時を記録する。
- 予定件数>0・取得件数一致・終了コード0を確認する。途中のPASS表示やJSONだけで全体完了としない。

## A. 開始前

- [ ] `git status --short` を確認し、他の変更を壊さない
- [ ] `node tests/scene-variation.cjs` が変更前に PASS
- [ ] `bgm_forge_standalone.html` を直接編集していない
- [ ] 変更対象と検証対象の場面・音色・尺・seedを決めた

## B. 作曲・譜面の決定性

- [ ] 同じ設定とseedで同じ fingerprint が得られる
- [ ] `events(score)` が同じイベント列を返す
- [ ] `Math.random()` に依存していない
- [ ] 旋律・内声・パッド・低音・打楽器のイベントが仕様外のpart番号になっていない
- [ ] MIDI音域外の音がない
- [ ] NaN、Infinity、負のdurationがない
- [ ] 旋律がある設定で、旋律が意図せず全休符になっていない

## C. 尺・長尺構成

- [ ] 20/30秒の短尺が従来の実尺仕様を満たす
- [ ] 60/90/120秒が指定尺未満にならない
- [ ] 長尺テーマが16小節になる
- [ ] 内声休止区間が予定位置にある
- [ ] 90/120秒の別型を対象経路ごとに確認（autoPattern/手動経路の未対応は課題として記録）
- [ ] 120秒は90秒と同じ休止・復帰・B・接続を保ち、90秒版の実尺以降にAを追加する（場面専用経路）
- [ ] 新規作曲と編集による延長の両方を検証した
- [ ] `autoPattern`、場面専用伴奏、手動伴奏の全経路を検証した

## D. 伴奏・場面差

- [ ] 同じ設定で場面ごとの伴奏形が衝突していない
- [ ] arrangement variant が複数存在する
- [ ] 場面内の音符密度が極端に振れていない
- [ ] 音域住み分け（旋律と内声の間隔）が維持される
- [ ] パッドが宣言された音域内に収まる
- [ ] 旋律を無効にしても伴奏の音域・リズムが不必要に変わらない

## E. 音声レンダリング

- [ ] 生成エラーがない
- [ ] 出力が空でない
- [ ] サンプルレート・チャンネル数が期待値どおり
- [ ] 振幅が上限を超えない
- [ ] 完全無音にならない（無音を仕様とする区間を除く）
- [ ] パート別の音量が想定外に突出しない
- [ ] ループ接続前後の波形差・音量差を記録した（クリック・自然さの合否は人間試聴で判定）
- [ ] MP3保存後にも再生できる

## F. 配布物・公開

- [ ] `python3 scripts/build_standalone.py` を実行した
- [ ] 分割版と単体版の埋め込みコードが一致する
- [ ] `bgm_forge.html` の `?v=` が各JSのSHA-256と一致する
- [ ] 単体版に外部送信機能の痕跡がない
- [ ] クレジット・ライセンスが維持されている
- [ ] 820px と390pxで画面を確認した
- [ ] 公開後のサイトで変更が反映されている

## 記録欄

```text
commit:
検証日時:
実行者:
対象変更:
対象場面:
対象音色:
対象尺:
seed:
自動テスト結果:
音声測定結果:
未確認事項:
```
